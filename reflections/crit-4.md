# Crit 4 reflection

**What was the breakthrough that moved the work forward?**

I started by trying to figure out which instruments would actually go well
together, and landed on marimba, bells and bass because they complement each
other. The harder part was making them work together as one instrument when I
could give almost no instructions — the website itself had to be
self-explanatory, so the layout and the sound had to do all the teaching.

**What did this work change about who I want to be as a software developer?**

It changed how I rank my priorities. Making something easy to use should be
one of the first things I care about, not something I add at the end. A
website that anyone can pick up and understand without being told what to do
is, to me, the best kind of website — and I actually wrote that down while I
was building this, because it felt like something worth holding onto.
